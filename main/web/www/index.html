    Discovery

    Normally LANDA.SH pings every address on your network every few minutes to see what is there. In quiet mode it stops: it only notices devices it happens to hear from, so it finds far fewer, and it can no longer tell when a device leaves, so nothing is shown going offline. It still asks devices for their names, and port scanning below carries on unless you turn it off.

    Port scanning

    Secret vault

     

    At least 8 characters. The key is derived from this every time and is never stored, so losing it means losing the secrets. There is no reset that keeps them.

    What this does and does not do: a locked vault keeps credentials out of the web UI and out of the device export, and a flash dump yields only PBKDF2-hardened ciphertext. It does not protect against someone watching LAN traffic while the vault is unlocked: the dashboard is served over plain HTTP, so a revealed secret crosses the network in the clear.

    Firmware updates

    Backup

    One file that sets up a replacement dongle exactly like this one - Wi-Fi password included. Protected by a passphrase you choose now; the vault's secrets stay encrypted under the vault passphrase as well. Keep the file somewhere safe: with the passphrase, it gets whoever has it onto your Wi-Fi.

    Device list

    A JSON copy of every device the dongle knows, with the nicknames and types you have given them, for a spreadsheet or another tool. Moving to a new dongle? Use Backup, above.

    Restart and reset

    A reboot keeps everything. A factory reset clears the Wi-Fi credentials, the device list, the dashboard and the vault, and brings the dongle back up as an access point (uploaded icons included). There is no undo.

    Event log

    Everything the dongle has seen, newest first. The short list of things worth acting on is behind the bell.
